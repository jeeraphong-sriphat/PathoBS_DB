# ระบบบันทึกการขอตัวอย่าง (Specimen Request Log)

Google Apps Script web app ที่ผูกกับ Google Sheet ID
`1-s6pEGwCIo3baZ__GlMxDpMyJNFF8qUnA87rCk7ELY4`

## โครงสร้างไฟล์
- `Code.gs` — backend ทั้งหมด (บันทึก/ค้นหา/อัปเดต/dashboard)
- `Index.html` — โครงหน้าเว็บ + เมนู 4 ขั้นตอน
- `Stylesheet.html` — ดีไซน์/สี
- `JavaScript.html` — ตรรกะฝั่งหน้าเว็บ (ค้นหา, ลายเซ็น, dashboard)

## ขั้นตอนติดตั้ง

1. เปิด Google Sheet ที่ระบุ → **Extensions > Apps Script**
2. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ที่ Apps Script สร้างให้ แล้ววางโค้ดจาก `Code.gs` ที่ให้มาแทน
3. สร้างไฟล์ HTML 3 ไฟล์ในโปรเจกต์ Apps Script (คลิก `+` > HTML) ชื่อ `Index`, `Stylesheet`, `JavaScript` แล้ววางโค้ดตามไฟล์ที่ให้มา (**ชื่อไฟล์ต้องตรงกันเป๊ะ ไม่ต้องใส่ .html ตอนตั้งชื่อในตัวแก้ไข**)
4. กลับไปที่ `Code.gs` เลือกฟังก์ชัน `setupSheets` จากเมนู dropdown ด้านบน แล้วกด **Run** ครั้งเดียว
   - จะสร้างชีต `Data` พร้อมหัวตาราง และชีต `dropdownlist` ตัวอย่าง (ถ้ายังไม่มี) — ถ้ามีอยู่แล้วจะไม่ทับข้อมูลเดิม
   - ถ้าเคย Run มาก่อนแล้ว (มีชีต `Data`/`dropdownlist` อยู่แล้ว) ให้ Run ซ้ำอีกครั้งได้เลย — ฟังก์ชันนี้จะช่วยเติมคอลัมน์ที่ขาด (เช่น "ผู้บันทึกคำขอ" และคอลัมน์ "ผู้บันทึก" ใน dropdownlist) ต่อท้ายให้อัตโนมัติ โดยไม่แตะข้อมูลเดิมที่มีอยู่
   - ครั้งแรกที่ Run จะมีหน้าต่างขออนุญาต (Authorize) ให้กด "Continue" แล้วเลือกบัญชีของ รพ. และกด "Allow"
5. Deploy > New deployment > เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: เลือกตามนโยบาย รพ. (เช่น "Anyone within [domain]")
6. คัดลอก URL ที่ได้ไปแชร์ให้เจ้าหน้าที่ใช้งาน

## ชีต "dropdownlist" — ปรับตัวเลือกได้เองโดยไม่ต้องแก้โค้ด
แถวที่ 1 = ชื่อหัวข้อ (ต้องตรงกับชื่อฟิลด์เป๊ะ), แถวถัดไป = ตัวเลือก

| ห้องปฏิบัติการพยาธิฯ | หน่วยงานที่ขอ | ผู้บันทึก |
|---|---|---|
| พยาธิวิทยากายวิภาค | หอผู้ป่วยศัลยกรรม | เจ้าหน้าที่ A |
| พยาธิวิทยาคลินิก | ห้องฉุกเฉิน | เจ้าหน้าที่ B |
| นิติเวช | ... | ... |

- ทั้ง 3 คอลัมน์ (**ห้องปฏิบัติการพยาธิฯ**, **หน่วยงานที่ขอ**, **ผู้บันทึก**) เป็น dropdown ในหน้าเว็บแอปเสมอ
- ทุก dropdown มีตัวเลือก **"อื่นๆ (ระบุเอง)"** ต่อท้ายให้อัตโนมัติ — เลือกแล้วจะมีช่องกรอกข้อความโผล่มาให้พิมพ์เอง กรณีไม่มีในลิสต์
- **"ผู้บันทึก"** ใช้เลือกชื่อเจ้าหน้าที่ห้องปฏิบัติการที่บันทึกรายการ — โชว์เฉพาะขั้นตอนที่ 1 (บันทึกคำขอ) และขั้นตอนที่ 3 (จำหน่ายออก) เพื่อให้ตรวจสอบย้อนหลังได้ว่าใครทำขั้นตอนไหน (ขั้นตอนที่ 2 ใช้ฟิลด์ "ผู้รับตัวอย่าง" อยู่แล้ว จึงไม่มีฟิลด์ผู้บันทึกซ้ำ)
- เพิ่ม/ลบตัวเลือกได้ทันทีโดยแก้ในชีตนี้ ไม่ต้องแก้โค้ด — แค่รีเฟรชหน้าเว็บแอป

## ลำดับการทำงาน (สถานะ)
`รอรับตัวอย่าง` → (ขั้นตอน 2) → `รับตัวอย่างแล้ว` → (ขั้นตอน 3) → `จำหน่ายแล้ว`

- ขั้นตอนที่ 2 และ 3 จะค้นหาได้เฉพาะรายการที่ "คงค้าง" อยู่ในสถานะก่อนหน้าเท่านั้น (กันบันทึกซ้ำ/ข้ามขั้นตอน)
- Dashboard แสดงจำนวนคงค้างแยกเป็น "รอรับตัวอย่าง" และ "รอจำหน่ายออก" พร้อมตารางกรองตามสถานะ/ช่วงวันที่/คำค้นหา

## หมายเหตุเกี่ยวกับลายเซ็น
ลายเซ็นที่วาดในขั้นตอนที่ 3 จะถูกแปลงเป็นรูปภาพ (base64 PNG) แล้วเก็บไว้ในคอลัมน์ "ลายเซ็น" ของชีต `Data` โดยตรง — เปิดดูได้โดยคัดลอกค่าไปใส่ในเบราว์เซอร์ หรือจะให้ผมเพิ่มฟังก์ชันแสดงลายเซ็นในหน้า Dashboard/ใบรายงานเพิ่มก็แจ้งได้

## ยังไม่ได้ทำ (รอข้อมูลเพิ่มเติม)
- การเชื่อมกับชีต `ReportForm` เพื่อพิมพ์ใบรายงานรายรายการ — ยังไม่ทราบโครงสร้างเทมเพลตที่มีอยู่ ถ้าต้องการให้ต่อยอด ส่งโครงสร้าง/รูปแบบของชีต `ReportForm` มาได้เลย
